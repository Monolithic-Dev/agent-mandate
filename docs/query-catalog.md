```cypher
RETURN count(w) AS deleted
```

## w34_record_delivery

```cypher
MATCH (w:Webhook {id: $webhook_id})
CREATE (w)-[:DELIVERED]->(d:Delivery {id: $id, webhook_id: $webhook_id, event: $event,
  at: $at, ok: $ok, attempts: $attempts, status: $status, error: $error,
  duration_ms: $duration_ms, subject: $subject})
RETURN d.id AS id
```

## w35_prune_deliveries

```cypher
MATCH (:Webhook {id: $webhook_id})-[:DELIVERED]->(d:Delivery)
WITH d ORDER BY d.at DESC, d.id DESC
SKIP $keep
DETACH DELETE d
RETURN count(d) AS pruned
```
